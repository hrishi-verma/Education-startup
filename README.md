# Education-startup

_Chads — tentative name_

A visual, chunk-based coding education platform. Students build reusable
problem-solving **chunks**, then compose them into patterns and independently
solve unfamiliar problems — with deliberate training of **forward intuition**.

## Run it
```bash
npm install
npm run dev        # http://localhost:3000  (roadmap → Two Pointers is live)
# or: npm run build && npm run start
```
